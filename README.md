## Практическая работа №2

### Hero

Добавлены методы: `TakeDamage`, `Heal`, `GainExperience`, `IsAlive`, `GetInfo`.

Проверка недопустимого урона: `yaroslav.TakeDamage(-20)` не изменил здоровье (75 → 75).  
Проверка сильного урона: `artem.TakeDamage(200)` остановил здоровье на 0.

Итог: Ярослав — 85 HP, 65 XP; Анастасия — 60 HP, 0 XP; Артём — 0 HP, 0 XP.

### Собственный класс

Добавлен метод `Restock(int amount)` — пополнение количества товара.  
Параметр `amount` — сколько единиц добавить.  
Защита: если `amount <= 0`, метод возвращается без изменений.  
Проверка: было 5 → Restock(3) → 8 → Restock(-2) → 8.
